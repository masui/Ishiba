# MaskIshiba

ブラウザに前首相（石破茂）の顔写真が出てきたら、ぼかす・黒く塗る・別の画像に置き換える Chrome 拡張機能。

## インストール

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリ (`/Users/masui/Ishiba`) を選ぶ
4. ツールバーのアイコンから設定

`demo.html` をブラウザで開くと動作確認できます（`file://` で試す場合は拡張機能の詳細で
「ファイルの URL へのアクセスを許可する」を ON にしてください）。

## どうやって顔を見つけているか

ブラウザ内で本物の顔認識モデルを動かすと重いので、**画像の周辺情報**で判定しています。

| 判定の強さ | 見るもの |
|---|---|
| 厳しめ | `alt` / `title` / 画像ファイル名・URL（`ishiba`, `石破` …） |
| ふつう（既定） | 上記＋ `figcaption`、リンクのテキストや href、画像を囲む短いテキスト（400文字以内）、**投稿・記事ブロック単位の本文**（3000文字以内） |
| ゆるめ | 名前が出てくるページなら、そのページの画像を全部 |

ニュースサイトは写真に説明文やキャプションが付いているので、「ふつう」でだいたい引っかかります。
取りこぼす場合は「ゆるめ」にしてください。

### SNS（Facebook / X など）

Facebook は画像の `alt` が「1人、テキストの画像のようです」のような自動生成文で、URL も
`scontent.xxx.fbcdn.net/…` のハッシュなので、画像そのものには手がかりがありません。本文も DOM 上で
画像から離れた場所にあります。そこで **投稿ブロック（`[role="article"]` / `article` / `[role="listitem"]`
/ `[class*="post"]` など）を単位にして、その中の本文に名前があれば中の画像をマスク**します。
1投稿とみなせる範囲（3000文字以内）に限定しているので、フィード全体が巻き込まれることはありません。

React の SPA は画像より後から本文が届くことがあるため、一度「対象でない」と判定した画像も
数回はやり直します（`MAX_TRIES`）。

それでも消えない場合の調べ方 — 開発者ツールのコンソールで:

```js
[...document.images].filter(i => i.offsetWidth > 100).slice(0, 20).map(i => ({
  alt: i.alt,
  src: i.currentSrc.slice(0, 60),
  post: (i.closest('[role="article"],article,[role="listitem"]')?.textContent || '').slice(0, 100)
}))
```

`alt` にも `src` にも `post` にも名前が出てこないなら、そのページでは文脈から判定しようがないので
「ゆるめ」にしてください（そのサイトの画像を全部マスクします）。

## 「一瞬見えてしまう」対策

判定してからマスクするので放っておくと素の画像がちらっと見えます。2段構えで防いでいます。

1. **挿入と同時にマスク** — `MutationObserver` で DOM に `<img>` が挿入された瞬間に同期でマスクします。
   MutationObserver のコールバックは描画より前に走るので、画像データが届く前に間に合います。
   （以前は判定を `requestIdleCallback` に回していたため、そこで見えていました）
2. **先読みブラー** — ページの URL・`<title>`・流れてくるテキストに名前が出てきた時点で、
   判定が終わるまで**そのページの画像を一律ぼかし**ます。判定が済んだ時点（`DOMContentLoaded` 以降の
   スキャン後）に解除され、無関係な画像は元に戻ります。CSS は `document_start` で注入されるので
   最初の描画に間に合います。設定でオフにできます。

名前が本文のずっと後ろにしか出てこないページでは、それより前に描画された画像が一瞬見えることは
まだあり得ます（先読みブラーを掛ける根拠がその時点では無いため）。確実に防ぎたい場合は
「ゆるめ」＋「先読みブラー」の組み合わせが最も強力です。

## 処理の種類

- **ぼかす**（強さを 2〜60px で調整）
- **黒く塗りつぶす**
- **別の画像に置き換える**（絵文字、または任意の画像 URL）
- **非表示にする**

そのほか:

- 先読みブラー（既定 ON、上記）
- マウスオーバーで一時的に元画像を表示（既定 OFF。ON にするとホバー中だけ元画像が見えます）
- 本文中の名前も黒く塗りつぶす（既定 OFF）
- サイトごとの無効化（ポップアップのいちばん下のボタン）
- キーワードの編集 — 別の人物に切り替えたい場合はここを書き換えるだけで動きます
- マスクした枚数がツールバーのバッジに出ます

遅延読み込みや SPA の画面遷移は `MutationObserver` で追随します。40px 未満の画像はアイコンとみなして無視します。

## 元画像を本当に見せたくない場合

- ポップアップの「マウスを乗せたら一時的に元に戻す」を OFF にする（既定 OFF）。
- ただし**ぼかす／黒く塗る**は CSS の `filter` を掛けているだけなので、元の画像は DOM に残り、
  ダウンロードもされています（開発者ツールや「画像を新しいタブで開く」では見えます）。
  完全に画面から消したいなら **「別の画像に置き換える」か「非表示にする」** を選んでください。
  こちらは `src` 属性そのものを差し替える／描画しないので、ホバーでも元画像は出てきません。
